# order-processor-lab

Учебный проект для лабораторной работы по GitHub Copilot Agent Skills.


## Установка

```bash
pip install pydantic pytest
```

## Запуск тестов

```bash
pytest -v
```

Skill `order-standards` хранит правила создания и валидации моделей Pydantic. Эталон находится в `references/order_schema_v2.py`.
